# Week 1 reflection

Answer each question in 1–3 sentences, in your own words.

1. What is the difference between building a UI imperatively (plain DOM code) and declaratively (React)?
   Imperative UI building tells the browser how to create and update elements step by step. Declarative React code describes what the UI should look like

2. Why must a component name start with a capital letter?
   Component names must start with a capital letter so React knows they are custom components rather than regular HTML elements

3. What does a fragment <>...</> do, and why not just use a <div>?
   groups multiple elements without adding an extra element to the DOM. It keeps the HTML structure cleaner than using <div>

4. Name one benefit of splitting the UI into small components.
   Splitting the UI into small components makes the code easier to understand, reuse, and maintain.
